The Game of Backgammon

Backgammon is a popular board game, providing an intriguing combination of skill and luck. Its essentially modern form first arose in Persia during the 6th century CE. Its most recent innovation, the doubling cube, was introduced in the 1920s. However, its origins date back some 5,000 years.

Using the software described here you can:

  1. Play the game against another human being via the web. The two of you may reside on different continents!
  2. Play the game against any of nine built-in AI brains.
  3. Set up the board and analyze any position.
  4. Design your own AI and evolve it via a genetic algorithm.
  5. Run a tournament among AIs you design or choose from the existing list.

To play the game you can click on the top headline of this page or on the image in Figure 1. You'll see a game board and a column of controls. each control has a tooltip popup that you'll see if you hover over the control. The second line of the control column is a link back to this page. The Game Board

In the default view of the game board, as shown in Figure 1, the home board of White is in the lower right quadrant, and White's outer board is in the lower left. Similarly, Red's home and outer boards are on the top, on the right and left, respectively. Red moves from the white home board to the red home board and White moves in the opposite direction. Both players move from their opponent's home board to their own home board, and from there to the collecting tray next to the home boards. Red moves clockwise, and white moves counterclockwise. The bar contains any checkers that have been forced off the board by the opponent, and the collection tray receives all checkers that have been born off. The points of the board are numbered from 1 to 24. It is sometimes convenient to think of the bar as point 25 for White and 0 for red, and the collection tray as point 0 for white and 25 for Red. With these conventions, Red always moves from some point to a point with a larger index, and White moves to a point with a smaller index. The default view is Red's view as it would be on a physical board. That view is consistent with the diagrams shown in this external rules page. You can change the view of the board, as described below.

There are several ways to move a checker from point x to point y on the game board. You can drag it from x to y or you can first click on x and then on y. There is also a setting (see the description of row 18) that let's you move a checker with a single click of that click uniquely identifies the move.

If the move is part of a game the system will only make legal moves. However, there is also an examination mode, see the description of row 12, that let's you move checkers freely.

1Title and Parallel Processing

This line contains the name of the game, BACKGAMMON, and the current version number. Together they constitute a clickable link that takes you to this manual page.

Workers are individual processes that you computer lets you run in parallel. The software obtains the available number of workers from your computer and by default uses that number of workers to run tournaments and evolutions, or individual games against AIs that search more than one move ahead. You can replace the default number by any other positive integer. Using fewer than workers than are available may slow down your computations, but it may be advantageous when you re running other CPU intensive processes on your system. Specifying more than the available number of workers is possible, but not likely to be useful. Many computers offer 8 processes, but you may have many more.

3 Playing Over the Network

These controls let you set up a match between two human players in two different locations. Both of you have to have an internet connection, and you also have to have an open communication channel to your opponent, by telephone, on screen, or by email. One of you serves as the host, the other as the guest. To set up a match proceed as follows:
  1. As host click on the button labeled HOST. A code (usually a three digit integer) will appear in the text field labeled CODE. Communicate that code to the Guest.
  2. As guest enter the code into your CODE text field, by clicking on the word CODE and typing the code for your game. The word CODE will disappear in the process. Establish the connection by press the enter key, or by clicking on the button labeled JOIN. Once the connection is established a notification will appear in Line 4.
  3. As host click on Start (in row 5) and then click on the playing dice in row 9 to determine who starts the game. If you have already played a game, and you want to play another, as host click on RESTART in row 5.
  4. The two of you can then play a game as described above in the section headed The Game Board.
  5. The LEAVE button severs the network connection. It does not reload the page or reset the board; it simply disconnects you from your opponent and restores your local privileges (such as time travel and starting a local game), so either player can leave and continue on their own computer.

    Notes:

  6. The host always plays as White, the guest as Red. Either player may be the first to roll the dice. In the first game, the first player to roll the dice is determined by random. Thereafter the beginning player alternates.
  7. The Host's view by default is White, that of the guest is Red.
  8. Either of the two players can act as host, but the guest does not have all the privileges that the host has. The main purpose of this restriction is to remove sources of confusion. In particular the guest cannot restart a game, or navigate back and forth within the game (see the description of row 10).

5Game Control

These buttons let you start or stop and stop a game. The start button also serves to continue a game after an interruption. The Restart button stops a game and resets to the board to the initial configuration. The reset button reloads the game page and thereby returns all settings to their default status.

6 7Player Selection

Here you can select the white player in the first menu in that row.. The options are either Human (the default) or one of one of 9 AI players, ranked by decreasing performance. The cyan text field keeps track of the score in a multi game match. The button labeled Z resets the score field to zero. The depth menu let's you select the search depth for AI players, measured in plies (half moves). 1 ply is the default, and overall by far the most useful setting. At 0 plies picks picks the first available legal move. You can use it if you are looking for an easy opponent. 1 ply applies a static evolution function to every board that can be obtained with a legal move. It then picks the move that yields the best scoring board. This is very fast, for human play as well as for tournaments or evolutions. 2 ply considers all possible dice rolls and moves after the first ply, and then computes an expected score for the board after the first ply. A two ply search is a few percentage points better than one ply search, but it requires several seconds for each search. It is a reasonable choice for a human playing against an AI. A 3 ply search goes one ply deeper, but it's utility is severely limited by the large amount of time it takes for the analysis of just one dice roll.

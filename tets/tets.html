Display Mode
Press W or w to go to work,
X or ESC to show controls,
F to go fullscreen,
P to take a screenshot,
A to toggle animation,
C to clear this text
R to record with constant opacity,
r to record with dynamic opacity),
Press ESC to exit full screen
or X to toggle the controls
Keyboard Commands

w, W : Go to Work
f, F : Toggle Full Screen
x, X : Toggle Controls (Sidebar)
r / R : Record (Dynamic / Constant Opacity)
l, L : Toggle Camera Orbit Path
p, P : Save Screenshot (PNG)
a, A : Toggle Animation
v, V : Anim. Duration (- / +)
ESC : Exit Full/Controls
s, S (Hold) : Auto-slice (Away/Towards)
o, O : Opacity (- / +)
e, E : Explosion (- / +)
b, B : Toggle Centroid Balls
i, I : Toggle Global Indices
h, H : Toggle Hover Info
m, M : Open User Manual
< , > : Scale Index Size (- / +)
? : Toggle this help menu
